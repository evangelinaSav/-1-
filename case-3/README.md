# «Проходной порог»

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/evangelinaSav/case-BScStat/blob/main/case-3/notebook.ipynb)

## 🎯 Задача
Подобрать количество вопросов и уровень сложности вступительного теста на внимательность так, чтобы сильные кандидаты проходили тест с вероятностью не менее 80%, а слабые — отсеивались с вероятностью не менее 70%.

## 📊 Данные
Вероятности правильного ответа сильного и слабого кандидата на вопрос трёх уровней сложности (проще/как на работе/сложнее, чем на работе).

## 🔍 Подход
- Ответы кандидата на вопросы теста смоделированы биномиальным распределением
- Для каждого уровня сложности и количества вопросов (от 0 до 100) рассчитан оптимальный проходной порог (через `scipy.stats.binom.ppf`) и соответствующая вероятность прохождения слабым кандидатом
- Построены графики зависимости вероятности прохождения от порога и от количества вопросов
- Найдено минимальное количество вопросов, при котором выполняются оба требования
- Сравнены все три уровня сложности между собой

## ✅ Результат
Уровень сложности «как на работе» выбран как оптимальный — позволяет уложиться в разумное количество вопросов, не делая тест ни слишком длинным, ни слишком простым/сложным.
