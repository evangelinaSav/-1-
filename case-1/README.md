# «Золотая жила»

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/evangelinaSav/case-BScStat/blob/main/case-1/notebook.ipynb)

## 🎯 Задача
Найти наиболее прибыльную категорию клиентов по полу и возрасту для платформы изучения иностранного языка, чтобы таргетировать привлечение 1000 новых клиентов при средней стоимости привлечения 15 000 ₽.

## 📊 Данные
Датасет `golden_mine.csv`: платежи, себестоимость обслуживания, прибыль, пол, возраст и возрастная категория текущих клиентов.

## 🔍 Подход
- Обзор данных (`info`, `describe`) и поиск выбросов через boxplot по платежам, себестоимости и прибыли
- Удаление единичных выбросов (аномально высокие платежи и расходы)
- Расчёт медианной прибыли по всей базе и сравнение со стоимостью привлечения
- Сравнение медианной прибыли мужчин и женщин 18–24 лет
- Тепловая карта медианной прибыли по полу и исходным возрастным группам
- Пересборка более мелких возрастных групп (шаг 1–2 года) и повторная тепловая карта — поиск «золотой жилы», скрытой в укрупнённых группах
- Детализация медианной прибыли по каждому отдельному возрасту и полу

## ✅ Результат
При исходной разбивке на широкие возрастные категории самая выгодная группа была не видна. После сужения возрастных диапазонов найдена конкретная половозрастная категория с заметно более высокой медианной прибылью — «золотая жила» для таргетированного привлечения.
