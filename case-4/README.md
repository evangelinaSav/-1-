## 🎯 Задача
Найти наиболее прибыльную категорию клиентов по полу и возрасту для таргетированного привлечения новых пользователей платформы изучения иностранного языка, при стоимости привлечения одного клиента 15 000 ₽.

## 📊 Данные
Прибыль, пол, возраст и возрастная категория текущих клиентов платформы.

## 🔍 Подход
- Z-тест на то, что средняя прибыль по всей базе клиентов статистически значимо превышает стоимость привлечения
- Сравнение прибыльности мужчин и женщин 18–24 лет между собой и по отдельности со стоимостью привлечения
- Перебор узких половозрастных сегментов для поиска сегмента с максимальной средней прибылью — «золотой жилы»
- Сравнение найденного сегмента с общей категорией «женщины 18–24»
- Расчёт минимально детектируемого эффекта (MDE) для отдельного теста и для серии тестов с поправкой на множественное тестирование

## ✅ Результат
Привлечение клиентов без таргетирования статистически окупается, но узкий сегмент «мужчины 22–23 лет» («золотая жила») приносит ощутимо больше прибыли на клиента, чем общая категория женщин 18–24 — итоговая рекомендация таргетироваться именно на него.
