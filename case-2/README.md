## 🎯 Задача
Учебная задача на манипуляцию данными: показать, как некорректный отбор выборки может «доказать» два противоположных вывода об одном и том же A/B-тесте. Нужно было отобрать по 200 пользователей продукта A и продукта B так, чтобы вывод получился в пользу нужного продукта — сначала в пользу A, затем в пользу B.

## 📊 Данные
Данные о 500 пользователях на каждый продукт: пол, возраст, тип предложения (A/B), количество просмотренного видеоконтента.

## 🔍 Подход
- Для каждого сценария («друг — A» и «друг — B») отобраны выборки по 200 пользователей: у нужного продукта брались пользователи с наибольшим количеством просмотров, у ненужного — с наименьшим
- Построены столбчатые диаграммы суммарной вовлечённости по продуктам для обоих сценариев
- Дополнительно построено распределение пола и возраста в отобранных выборках

## ✅ Результат
Показано, что при пристрастном отборе выборки можно получить любой желаемый вывод — иллюстрация того, почему методология отбора данных критична для честности A/B-теста.
